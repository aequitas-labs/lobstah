# Working on lobstah

- A PR carries only its change.
- Edit docs only when user-facing behavior changes.
- Do not add CSS or style tests.
- Do not commit screenshots.
- Product copy (anything a person reads in the product) follows the `product-copy` skill.
- Writing for Chris or engineers (PRs, commits, issues, plans, reports, docs) follows the `plain-technical-writing` skill.
