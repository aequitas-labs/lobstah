# Working on lobstah

Before you write anything a person reads in the product (screens, buttons, errors, emails, texts, notifications), read the `product-copy` skill in full. Before you write a PR description, report, plan or review comment, read the `plain-technical-writing` skill in full.

- A PR carries only its change.
- Edit docs only when user-facing behavior changes.
- Do not add CSS or style tests.
- Do not commit screenshots.
