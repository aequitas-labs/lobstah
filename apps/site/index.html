Nobody stares at the water.

Set your traps and go do something else. lobstah runs your coding agents in the background and tells you when one has a catch, or a question.

Harness-agnostic, token-efficient supervision for coding agents.

npm i -g lobstah

Open source, MIT. Node 20 or later. macOS, Linux, Windows. Other ways to install

Set the traps.

Lob a brief into a trap and walk away. Each job runs in its own git worktree, on Claude Code or Codex. Set one trap or set ten.

Go do something else.

A trap doesn't fish faster for being watched, and an agent doesn't code faster either. A daemon does the watching, with no model in the loop.

The buoy tells you.

Bobbing: it is working. Flag up: it needs a decision. Pulled under: a catch. Gone still: something stopped, and the helm already knows.

Workers report in six words: working, needs-decision, blocked, paused, done, failed. lobstah accepts no others.

Haul up the lobstahs.

You step in only when a catch is ready. The trap comes up with a pull request, the evidence, and a report.
